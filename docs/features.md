# 機能要件

[要件定義書](./requirements.md) の詳細ドキュメント。X風SNSアプリの機能要件（機能一覧と業務ルール）をまとめる。

- 画面ID（S-xx）は [画面仕様・画面遷移・ユースケース](./screens.md)、API ID（A-xx）は [API設計](./api.md) を参照
- 各分類の処理の流れ・エラー時の動き・受け入れ条件は、分類ごとの [機能定義書](./feature-specs/README.md) を参照

## 機能一覧

| ID | 機能名 | 分類 |
|---|---|---|

| F-20〜F-24 | フォロー中タイムライン、追加読み込み、全体タイムライン、タイムライン切り替え、新しい投稿のお知らせ | タイムライン |
| F-30〜F-32 | コメント投稿、コメント一覧、コメント削除 | コメント |
| F-40〜F-42 | いいね、いいね取り消し、いいね済み表示 | いいね |
| F-50〜F-52 | フォロー、フォロー解除、フォロー中・フォロワー一覧 | フォロー |
| F-60〜F-61 | プロフィール表示、プロフィール編集 | プロフィール |
| F-70〜F-71 | ユーザー検索、新しいユーザー一覧 | ユーザー検索 |

## 認証

→ [機能定義書：認証](./feature-specs/01_auth.md)

| ID | 機能名 | 内容 | 画面 | API |
|---|---|---|---|---|
| F-01 | 新規登録 | ユーザー名・表示名・メールアドレス・パスワードでアカウントを作る。登録後はそのままログイン状態にする | S-02 | A-01 |
| F-02 | ログイン | メールアドレスとパスワードでログインする | S-01 | A-02 |
| F-03 | ログアウト | ログアウトしてログイン画面に戻る（サーバーでリフレッシュトークンを無効にし、画面側のアクセストークンも捨てる） | 共通ヘッダー | A-05 |
| F-04 | ログインユーザー情報の取得 | 画面を開いたときに、リフレッシュトークンでアクセストークンを再発行してログイン状態を復元する。アクセストークン（15分）の期限が切れたら自動で再発行する | 全画面 | A-03, A-04 |

ユーザー情報の項目：

| 項目 | 必須 | 備考 |
|---|---|---|
| ユーザー名（`@xxx`） | 必須 | 半角英数字と `_`、4〜15文字。全ユーザーで重複不可（大文字・小文字は区別せずにチェックし、`Yamada` と `yamada` は同じとみなす）。登録後は変更不可 |
| 表示名 | 必須 | 1〜50文字。重複可。後から変更可。プロフィール編集で変更する「ユーザー名」はこの表示名のこと |
| メールアドレス | 必須 | 全ユーザーで重複不可。ログインに使う。小文字にそろえて保存する |
| パスワード | 必須 | 8〜72文字（上限は BCrypt が72バイトまでしか扱えないため） |
| 自己紹介 | 任意 | 160文字まで |
| アイコン画像 | 任意 | 未設定ならデフォルト画像を表示 |

## 投稿

→ [機能定義書：投稿](./feature-specs/02_post.md)

| ID | 機能名 | 内容 | 画面 | API |
|---|---|---|---|---|
| F-10 | 投稿作成 | テキスト（280文字まで）と画像（4枚まで）を投稿する | S-04 | A-11 |
| F-11 | 投稿編集 | 自分の投稿の本文を編集する。編集後は「編集済み」と表示する | S-05 | A-13 |
| F-12 | 投稿削除 | 自分の投稿を削除する。確認ダイアログを出す | S-03, S-06, S-07 | A-14 |
| F-13 | 投稿詳細表示 | 投稿1件と、その投稿へのコメント一覧を表示する | S-06 | A-12 |

| 項目 | 必須 | 備考 |
|---|---|---|
| 本文 | △ | 1〜280文字。画像があれば空でもよい（本文も画像もない投稿は不可） |
| 画像 | △ | 1投稿につき最大4枚。jpg / png / gif、1枚5MBまで |

操作：

- 作成・編集・削除（物理削除）ができる。編集・削除は自分の投稿だけ
- 編集できるのは本文のみ（画像は変更不可）。一度でも編集した投稿には「編集済み」と表示する
- 削除すると、その投稿の画像・コメント・いいねも消える

## タイムライン

→ [機能定義書：タイムライン](./feature-specs/03_timeline.md)

| ID | 機能名 | 内容 | 画面 | API |
|---|---|---|---|---|
| F-20 | フォロー中タイムライン表示 | 自分とフォロー中のユーザーの投稿を新しい順に20件表示する | S-03 | A-10 |
| F-21 | 追加読み込み（共通） | 下までスクロールすると、次の20件を自動で読み込む（無限スクロール）。どちらのタイムラインとプロフィールの投稿一覧でも使う | S-03, S-07 | A-10, A-15, A-61 |
| F-22 | 全体タイムライン表示 | 全ユーザーの投稿を新しい順に20件表示する | S-03 | A-15 |
| F-23 | タイムライン切り替え | ホーム画面上部のタブで「フォロー中」と「全体」を切り替える | S-03 | なし |
| F-24 | 新しい投稿のお知らせ | 60秒ごとに新しい投稿の件数だけを確認し、あれば「↑ N件の新しい投稿」ボタンを出す。一覧は勝手に増やさず、ボタン・表示中のタブ・ヘッダーの「ホーム」を押したときだけ最新を取り直す | S-03 | A-16, A-17 |

| 種類 | 表示対象 | 役割 |
|---|---|---|
| フォロー中（初期表示） | 自分の投稿 + フォロー中のユーザーの投稿 | 知り合いの投稿を追う |
| 全体 | 全ユーザーの投稿 | まだフォローしていない人を見つける。フォローが0人でも投稿が見られる |

- 並び順は投稿日時の新しい順。20件ずつ表示する
- 各投稿に出す情報：投稿者のアイコン・表示名・ユーザー名、投稿日時、本文、画像、コメント数、いいね数、自分がいいね済みか、編集済みか
- 出さない情報：インプレッション数、リツイート数（差別化のため）

## コメント

→ [機能定義書：コメント](./feature-specs/04_comment.md)

| ID | 機能名 | 内容 | 画面 | API |
|---|---|---|---|---|
| F-30 | コメント投稿 | 投稿にコメントする。投稿後、コメント数が1増える | S-06 | A-31 |
| F-31 | コメント一覧 | 投稿へのコメントを古い順に表示する | S-06 | A-30 |
| F-32 | コメント削除 | 自分のコメントを削除する。削除後、コメント数が1減る | S-06 | A-32 |

- 表示順は古い順（会話の流れが追いやすいため）

## フォロー

→ [機能定義書：フォロー](./feature-specs/06_follow.md)

| ID | 機能名 | 内容 | 画面 | API |
|---|---|---|---|---|
| F-50 | フォロー | 他のユーザーをフォローする | S-07, S-09, S-10 | A-50 |
| F-51 | フォロー解除 | フォローを解除する | S-07, S-09, S-10 | A-51 |
| F-52 | フォロー中・フォロワー一覧 | あるユーザーのフォロー中ユーザー・フォロワーの一覧を表示する | S-09 | A-52, A-53 |

- 自分自身はフォローできない。相手の承認は不要で、いつでも解除できる
- ユーザーのアイコン・表示名・`@ユーザー名` が表示されている場所では、どこでもクリックでその人のプロフィールへ移動できる（投稿カード・コメント・ユーザー一覧）

フォローする相手の見つけ方（4つの経路）：

| 経路 | フォローする場所 |
|---|---|
| ① ユーザー検索（`@ユーザー名`・表示名） | 検索結果の行のボタン、またはプロフィール |
| ② 投稿の投稿者名をクリック（タイムライン・投稿詳細） | プロフィール |
| ③ コメントした人の名前をクリック（投稿詳細） | プロフィール |
| ④ フォロー中・フォロワー一覧 | 一覧の行のボタン、またはプロフィール |

## ユーザー検索

→ [機能定義書：ユーザー検索](./feature-specs/08_user_search.md)

| ID | 機能名 | 内容 | 画面 | API |
|---|---|---|---|---|
| F-70 | ユーザー検索 | キーワードで、`@ユーザー名`・表示名が部分一致するユーザーを探す。結果から直接フォローできる | S-10 | A-70 |
| F-71 | 新しいユーザー一覧 | 検索キーワードが空のとき、最近登録したユーザーを新しい順に表示する | S-10 | A-70 |

| ルール | 内容 |
|---|---|
| 検索対象 | ユーザーのみ（投稿は検索しない） |
| 検索する項目 | `@ユーザー名` と表示名。どちらかにキーワードが含まれていればヒットする（部分一致） |
| 大文字・小文字 | 区別しない |
| キーワード | 前後の空白と先頭の `@` を取り除いて検索する（`@yama` でも `yama` と同じ結果）。最大50文字。`%` `_` は普通の文字として扱う |
| キーワードが空 | 最近登録したユーザーを新しい順に表示する |
| 検索のタイミング | 入力が止まってから0.3秒後に自動で検索する。Enter キーでもすぐ検索できる |
| 並び順 | ①ユーザー名が完全一致 → ②ユーザー名が前方一致 → ③それ以外。同じ順位の中ではユーザー名の昇順 |
| 件数 | 20件ずつ表示する |
| 自分自身 | 結果に含める（フォローボタンは出さない） |
